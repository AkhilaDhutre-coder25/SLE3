# SLE-3: Architectural Design using Full C4 Model

## Course

02AML204 – Introduction to Artificial Intelligence

## System

BFS and DFS Graph Search System

## Description

This project presents the architectural design of a BFS and DFS Graph Search System using the Full C4 Model.

The system is designed to perform graph traversal using Breadth-First Search (BFS) and Depth-First Search (DFS). The architecture is represented using four C4 levels: Context, Container, Component, and Code.

## C4 Model Levels

### Level 1 – Context Diagram

Shows the BFS/DFS system and its interaction with the user.

### Level 2 – Container Diagram

Shows the main building blocks of the system such as input, search engine, visited/memory, and output.

### Level 3 – Component Diagram

Shows the internal components of the main Search Engine container.

### Level 4 – Code Level

Shows the main functions used in the BFS and DFS implementation.
